# ari3l97.github.io

The website for Block Breeze, served by GitHub Pages at <https://ari3l97.github.io>:

- `index.html`: home page with the store and support links
- `block-breeze/privacy-policy.html`: the privacy policy linked from the app and both stores
- `app-ads.txt`: tells ad buyers which AdMob account may sell ads in the app

The source files live in the `website/` folder of the Block Breeze repository; copy changes from there.
